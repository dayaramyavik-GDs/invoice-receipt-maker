# Invoice & Receipt Maker v0.1.2

First **signed** release. The app is signed with the project's own upload key (no longer Android's debug key),
and an Android App Bundle for Google Play is included.

## New since v0.1.1

- **Device codes** stop invoice-number clashes between phones: give each phone a code in Settings (e.g. `A`, `B`)
  and numbers become `INV-A-0001`, `INV-B-0001`. If a clash happened anyway, the dashboard names the duplicated
  number; voiding one copy clears it.
- **Sync is more reliable after airplane mode.** Some Android devices kept reporting "offline" after the network
  came back, so the app no longer depends on that and checks the server directly, re-checking every 30 seconds.
- **Smaller PDFs:** invoices with a logo dropped from ~319 KB to ~23 KB.
- Invoices whose customer was deleted keep showing (and saving) the customer's details.
- Layout fixes on newer Android versions (no blank band under the status bar).
- Server: the API image tag is `0.1.2`; MongoDB Atlas connection verified; Snyk scanning enabled in CI.
